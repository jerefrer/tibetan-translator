# Folio redesign mockups

Source of truth for sizes and colours; the spec wins where they disagree.

Boards (open the `.dc.html` files in a browser):

- `Main.dc.html`: Desktop · Lookup — trois volets
- `DesktopReader.dc.html`: Desktop · Reader — lire un texte, mot par mot
- `MobileHome.dc.html`: Mobile · Lookup, avant de taper
- `MobileResults.dc.html`: Mobile · Résultats pendant la frappe
- `MobileEntry.dc.html`: Mobile · Fiche d'un terme
- `MobileReader.dc.html`: Mobile · Reader et feuille de définition
- `MobileLibrary.dc.html`: Mobile · Library
- `UnifiedAuto.dc.html`: Un champ · A — Lu dans les deux sens
- `UnifiedToggle.dc.html`: Un champ · B — Bascule བོད / EN
- `UnifiedBridge.dc.html`: Un champ · C — Tibétain d'abord, passerelle vers les définitions
- `ModeTibetan.dc.html`: B · Mode tibétain : le Wylie se convertit
- `ModeNotWylie.dc.html`: B · Anglais tapé en mode tibétain : laissé tel quel
- `ModeAmbiguous.dc.html`: B · Mot anglais qui s'écrit comme du tibétain
- `ModeEnglish.dc.html`: B · Mode anglais : recherche dans les définitions
